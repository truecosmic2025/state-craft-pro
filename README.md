**The Simple Frame Robert Uses In Your Call:**

2. **Build the Scene:** One short, sensory‑rich moment **after** it’s achieved (touch/hearing/vision cues).

5. **Revision (as needed):** Re‑assign meaning to daily wobbles so momentum isn’t lost.

**Result:** A daily rhythm that **stabilises state**, so behaviour and opportunities naturally align.

# LOVABLE.DEV — COMPLETE STARTER PROMPT

**Goal:** Generate a production‑ready, elegant **glassmorphic** landing page that promotes a **free 1:1 consultation** with top imagination coach **Robert Meade** (Truecosmic Academy). Visual style should echo a premium spiritual/modern aesthetic with **Truecosmic brand colours**: deep **indigo** (primary), **cosmic gold** (accents), and **violet** (secondary). The page must be fast, accessible, and easy to A/B test.

## Build Requirements

* **Framework:** Next.js (App Router) + React + TypeScript. Tailwind CSS enabled. Use CSS variables for brand colours.
* **Design Language:** Glassmorphism (blurred, translucent cards), soft gradients, subtle noise texture, rounded‑2xl, balanced white space.
* **Components:** Hero, Social Proof, Problem→Promise, Mechanism (How It Works), Coach Bio, What You Get, Choose Your End (3 use cases), Booking Process, Testimonials, Why This Call, FAQ, Ethos/Safety, Final CTA, Footer.
* **Typography:** Modern humanist sans for body (e.g., Inter), elegant display for H1/H2 (e.g., Playfair Display or fraunces‑style). Large, legible sizes; good contrast.
* **Icons:** lucide‑react.
* **Scheduler:** Embed Calendly (or placeholder) for Robert’s availability.
* **Forms:** Name, email, primary goal (love/money/peace), biggest sticking point (dropdown), preferred time; client‑side validation.
* **Assets:** Placeholder for Robert portrait, coach quote, trust badges, testimonial avatars.
* **Animations:** Framer Motion; gentle fade/slide on viewport. Glass cards lift on hover. No parallax.
* **Performance:** LCP < 2.5s; lazy‑load below the fold images; compress SVGs. Avoid heavy libs.
* **Accessibility:** WCAG AA; semantic landmarks; focus rings; aria‑labels for CTAs; motion‑reduce support.
* **SEO:** Title/description tags, OpenGraph/Twitter cards, JSON‑LD (Organization + Service), favicon, robots, sitemap.
* **Analytics:** Placeholder for GA4/Meta Pixel. Consent banner placeholder.
* **Internationalisation Ready:** Text in constants; easy to localise.
